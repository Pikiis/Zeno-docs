# Privacy Policy

**Effective Date:** August 4, 2026

Privacy Policy for Zeno

Thank you for using Zeno, a Discord bot designed to provide moderation, automation, and server management features.

This Privacy Policy explains what information is processed by Zeno, how it is used, and your rights regarding your data.

## 1. Information We Collect
Depending on the features enabled by a server administrator, Zeno may process the following information:
Server Information
Server ID
Channel IDs
Role IDs
Message IDs
Configuration settings
Feature preferences
User Information
Discord User ID
Username and Display Name (when required)
Member Roles
Guild Membership Information
Message Information

When required by enabled features such as moderation, anti-spam, honeypot detection, sticky messages, or prefix commands, Zeno may temporarily process message content.
Message content is not permanently stored unless explicitly required by a feature configured by the server administrator.
Presence Information

If Presence Intent is enabled, Zeno may temporarily access user presence information (such as online status) solely for features that require it.

Presence data is never permanently stored.

## 2. How We Use Information
Information is processed only to provide Discord bot functionality, including:
Moderation
Welcome and Leave Messages
Reaction Roles
Sticky Messages
Server Automation
Anti-Spam Protection
Honeypot Detection
Voice Channel Utilities
Prefix Commands
Slash Commands
Administrator Configuration

We do not use collected information for advertising, marketing, profiling, or analytics unrelated to the bot's functionality.

## 3. Data Storage
Zeno stores only the information necessary to operate its features.

Examples include:

Server configuration
Feature settings
Role mappings
Welcome configuration
Sticky message configuration
Moderation configuration

Data is stored securely using MongoDB.

## 4. Message Content
Message content is processed only when necessary to provide enabled moderation or automation features.
Unless specifically required for an administrator-enabled feature, message content is not permanently stored.

## 5. Presence Data
Presence information is accessed only while required for bot functionality.
Presence data is never sold, shared, or permanently stored.

## 6. Data Sharing
Zeno does not sell, rent, or share user data with third parties.
Information is disclosed only when required by law or to comply with Discord's Developer Terms and Policies.

## 7. Data Security
Reasonable technical and organizational measures are implemented to protect stored data from unauthorized access, disclosure, or modification.

## 8. Data Retention

Server configuration data is retained only while the bot remains installed in the server.
If the bot is removed, server administrators may request deletion of stored configuration data.

## 9. User Rights
Server administrators may request:
deletion of stored server configuration,
information regarding stored configuration data,
removal of the bot from their server at any time.

## 10. Children's Privacy
Zeno is intended for use within Discord and does not knowingly collect personal information from children outside of information provided through Discord's platform.

## 11. Changes to this Privacy Policy
This Privacy Policy may be updated periodically.
The latest version will always be published at the official Privacy Policy page.

## 12. Contact
For questions regarding this Privacy Policy, please contact the developer through the official support server or GitHub repository associated with Zeno.
